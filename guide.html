규격과 템플릿 보기

Claude·Codex 를 쓴다면 스킬로 만들기도 있어요.

이미지 AI로 만들기

  1. 그림 한 장으로 만들기에서 프롬프트를 복사해요.
  2. ChatGPT·Gemini 같은 이미지 AI 에 붙여 넣어요. 캐릭터 사진이 있으면 같이요.
  3. 기본 모습을 승인하고, 동작을 고르거나 "알아서 해줘" 라고 해요.
  4. 받은 그림을 그 페이지에 올리면 동작별로 잘라 줘요.
  5. 떠기와 크기를 비교해 다듬고 zip 을 받아요.
  6. 앱 만들기 창에 zip 을 끌어다 놓아요.

가만히, 걷기, 잠자기만 있으면 올릴 수 있어요.

직접 그리기

동작마다 PNG 한 장. 프레임을 가로로 이어 붙여요.

규격

  • 캐릭터 프레임 96×48, 아이템 48×48. 동작당 최대 8프레임 (캐릭터 4프레임이면 384×48)
  • 캐릭터는 96칸 가운데에 그려요. 가로로 긴 캐릭터는 칸 가로를 다 써도 돼요
  • 투명 배경, 파일당 200KB 이하 (넘으면 앱이 다시 저장해 줄여요)
  • 효과음 wav 는 50KB 이하
  • 정면에 얼굴만 살짝 오른쪽, 또는 오른쪽을 보게 (왼쪽은 앱이 뒤집어요)
  • 캐릭터와 응가는 맨 아래 줄에 닿게, 가로 가운데
  • 던질 것·먹이는 프레임 가운데
  • 캐릭터 크기: 칠한 칸 800~1200개, 높이 30~46칸 (몸이 가늘면 더 크게)
  • 앱이 키우지 않아서 작게 그리면 친구 캐릭터 옆에서 작아 보여요

캐릭터 동작

idle, walk, sleep 만 있으면 돼요. 나머지는 '없으면' 칸 동작으로 대신해요.

동작언제권장없으면
idle 필수가만히2장, 2fps
walk 필수걸을 때4장, 6fps
sleep 필수30분 자리 비움 또는 화면 잠금 (Zzz 는 앱이 그림)2장, 1fps
poked콕 찔림2장, 8fpsidle
throw던질 때3장, 10fpsidle
hit맞았을 때2장, 8fpspoked
jump피할 때, 점프 동작2장, 8fpsidle
eat먹이 받을 때, 냠냠 동작3장, 6fpshappy
wave친구 접속 인사, 안녕 동작3장, 6fpshappy
happy쓰다듬기, 기쁨 동작2장, 4fpsidle
offline오프라인(쓰러진 모습)1장, 1fps돌

아이템 동작

동작언제권장없으면
fly 필수날아가는 동안. 응가는 바닥에 놓인 모습던질 것 1장, 먹이 1~4장, 12fps (응가는 1장)
impact맞는 순간 (던질 것만, 먹이는 바로 먹어요)3장, 12fps앱이 그리는 별 터짐
  • '날아갈 때 돌리기'를 켜면 앱이 돌려요(새로 만들면 꺼져 있어요)
  • 끈 던질 것은 가는 쪽을 보고 날아가요. 오른쪽을 보게 그려요
  • 끈 먹이는 그린 그대로 날아가요. 똑바로 선 채로 그려요
  • 멈춰 보이면 프레임으로 움직임을 줘요(통통 튀기, 반짝임)
  • 효과음은 닿는 순간(응가는 떨어질 때) 울려요
  • 효과음이 없으면 던질 것·먹이는 조용하고, 응가는 '뿡' 소리를 내요

예시: 뿅망치

기본 아이템이에요. fly 는 한 장뿐이지만 날아가는 동안 돌아요(먹이는 안 돌아요).

응가

  • fly 한 장이면 돼요. 바닥에 놓인 모습으로, 회전 없이 그려져요
  • 앱이 줄이지 않고 48×48 칸 그대로 그려요
  • 프레임 아래 가운데에 작게 그리고 위는 비워 둬요
  • 기본 응가는 폭 17·높이 12칸이에요
  • 똥 모양이 아니어도 돼요. 미니 호박, 관, 털실 같은 소품도 좋아요
  • 아래 가운데 24×24 안이면 돼요

실제 크기로 받기: idle, walk, sleep, poked, throw, hit, jump, eat, wave, happy, offline, 전체 받기(zip)

템플릿

  • 만들기 창 "템플릿 받기"로 동작마다 예시가 든 템플릿을 받아요(앱 햄찌, 아이템은 도토리)
  • 빈 템플릿: 2프레임, 4프레임, 8프레임, 전체 받기(zip)
  • 아래 레이어로 깔고 그린 뒤 템플릿 레이어는 끄고 저장해요
  • 빨간 줄이 발 기준선이에요
  • 그리는 도구: Piskel(웹, 무료), LibreSprite(무료), Aseprite(유료)

올리기 전 확인

  • 높이 48, 너비는 캐릭터 96·아이템 48의 배수, 8프레임 이하
  • 배경 투명, 템플릿 선 없음
  • 칸마다 네 모서리가 다 칠해지지 않음 (다 칠해지면 배경이 남은 걸로 보고 막아요)
  • 오른쪽을 보고, 발이 맨 아래, 프레임마다 위치 같음

올리기

  1. 트레이 메뉴 "캐릭터 > 만들기…"에서 캐릭터·아이템·이모트 탭을 골라요.
  2. "+ 새로 만들기"를 누르고 이름(20자까지)을 써요.
  3. 동작마다 PNG 를 고르거나 그 칸에 끌어다 놓아요.
  4. 저장하면 내 목록에 생겨요. 같은 곳에서 고치거나 지워요.
  • fps 는 권장값이 채워져 있어요
  • 아이템은 종류(던질 것·먹이·응가)와 효과음 wav 도 골라요
  • 캐릭터 바꾸기·아이템·이모트 고르기 창 맨 앞 + 카드로도 열려요
  • 내가 고른 캐릭터는 바로 보여요
  • 친구 화면엔 친구가 트레이 "캐릭터 > 바꾸기…" 창을 열거나 "새 캐릭터·아이템 받기"를 누를 때 들어가요

먹이·응가 쓰기

  • 먹이: 친구를 우클릭해 "먹이"에서 고른 뒤 친구를 클릭해요
  • 다시 "던질 것"을 고를 때까지 클릭마다 먹이를 줘요
  • 응가: fly 그림이 바닥에 떨어진 응가로 그려져요(던지거나 먹이로 안 써요)
  • 고른 응가로 내 캐릭터가 배부를 때 응가해요
  • 친구가 아직 안 받은 응가는 받을 때까지 기본 응가로 보여요

이모트

  • "이모트" 탭에서 GIF·WebP·APNG·PNG·JPG 를 골라요
  • 앱이 64px 로 줄여 원래 속도대로 저장해요
  • 같은 그룹 친구만 보여요
어디어떻게
머리 위내 캐릭터 메뉴 '이모트'(⌃⌥⌘E, Windows 는 Ctrl+Alt+E)
말풍선메시지에 : 를 치고 이름을 고르면 :이름: 으로 들어가요
상태상태·닉네임 창 '상태' 탭의 이모지 버튼
반응대화 기록에서 말에 붙여요
자세히
  • 16프레임까지 골라 저장해요
  • 원본 20MB, 가로·세로 2048px 까지
  • 이름은 20자까지, 그룹 안에서 겹치면 안 돼요
  • : 와 공백은 메시지 속 :이름: 이 끊겨서 못 써요
  • 기본 이모트 이름(heart·question·exclamation·angry·lol·note·쪽지)도 못 써요

한꺼번에 올리기

  • PNG 를 zip 하나로 묶어 만들기 창에 끌어다 놓아요
  • "한꺼번에 넣기"에서 zip 파일이나 폴더를 골라도 돼요
  • 넣기 전에 파일마다 들어갈 칸을 보여 줘요
  • 이름이 안 맞는 파일은 직접 칸을 골라요
  • 위 "전체 받기" zip 도 이 이름이라 그대로 넣어 볼 수 있어요

파일 이름은 동작 이름 그대로예요(대소문자 상관없음, zip 안 폴더 괜찮음).

  • 캐릭터: idle.png walk.png sleep.png poked.png throw.png hit.png jump.png eat.png wave.png happy.png offline.png
  • 아이템: fly.png impact.png, 효과음 sound.wav (응가는 fly.png 하나)

Claude·Codex 스킬로 만들기

  • 터미널에서 Claude Code·Codex 플러그인을 설치해요(아래 명령을 붙여 넣기)
  • 사진과 함께 "허기부기 캐릭터 만들어줘" 라고 해요
  • 동작 11개를 그려(원하면 응가·던질 것·먹이도) 위 '한꺼번에 올리기'로 넣을 zip 을 줘요
  • 새 버전은 플러그인 업데이트로 같이 바뀌어요
