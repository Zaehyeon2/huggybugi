查看規格和範本

如果你用 Claude 或 Codex，也可以用技能製作。

用圖像 AI 製作

  1. 在用一張圖製作裡複製提示詞。
  2. 貼到 ChatGPT、Gemini 之類的圖像 AI。有角色照片的話一起傳過去。
  3. 確認基本造型，然後選動作，或者說「你看著辦」。
  4. 把拿到的圖上傳到那個頁面，就會依動作切好。
  5. 和多基比較大小，調整好後下載 zip。
  6. 把 zip 拖到應用程式的製作視窗。

只要有靜止、走路、睡覺就能上傳。

自己畫

每個動作一張 PNG。把影格橫向接起來。

規格

  • 角色影格 96×48，物品 48×48。每個動作最多 8 格（角色 4 格就是 384×48）
  • 角色畫在 96 格的中間。橫向很長的角色可以用滿整個寬度
  • 透明背景，每個檔案不超過 200KB（超過的話應用程式會重新儲存來縮小）
  • 音效 wav 不超過 50KB
  • 正面，只有臉稍微朝右，或者整個朝右（朝左的由應用程式翻轉）
  • 角色和便便要貼著最下面一行，水平置中
  • 投擲物和食物放在影格的中央
  • 角色大小：塗色的格子 800~1200 個，高 30~46 格（身體細的話再大一點）
  • 應用程式不會放大，畫小了在朋友的角色旁邊會顯得小

角色動作

只要有 idle、walk、sleep 就行。其餘的由「沒有時」那一欄的動作代替。

動作時機建議沒有時
idle 必需站著不動2 格，2fps
walk 必需走路時4 格，6fps
sleep 必需離開 30 分鐘或螢幕鎖定（Zzz 由 App 畫）2 格，1fps
poked被戳2 格，8fpsidle
throw丟東西時3 格，10fpsidle
hit被打中時2 格，8fpspoked
jump閃躲時、跳躍動作2 格，8fpsidle
eat被餵食時、吃東西動作3 格，6fpshappy
wave跟上線的朋友打招呼、打招呼動作3 格，6fpshappy
happy被摸摸頭、開心動作2 格，4fpsidle
offline離線（倒下的樣子）1 格，1fps石頭

道具動作

動作時機建議沒有時
fly 必需飛行期間。便便是掉在地上的樣子可投擲 1 格，食物 1~4 格，12fps（便便 1 格）
impact打中的瞬間（只有可投擲，食物會直接被吃掉）3 格，12fpsApp 畫的星星爆開
  • 開啟「飛行時旋轉」，應用程式就會讓它轉（新建的預設是關的）
  • 關掉的投擲物會朝著飛行方向飛，請畫成朝右
  • 關掉的食物會照你畫的樣子飛，請畫成筆直站立
  • 看起來不動的話，用影格加點動作（彈跳、閃爍）
  • 音效在碰到的瞬間響（便便是落地時）
  • 沒有音效的話，投擲物和食物是靜音的，便便會發出「噗」的一聲

範本

  • 在製作視窗點「下載範本」，可以拿到每個動作都附範例的範本（應用程式裡的倉鼠，道具是橡實）
  • 空白範本：2 影格、4 影格、8 影格、下載全部（zip）
  • 墊在下面的圖層上畫，畫完關掉範本圖層再儲存
  • 紅線是腳的基準線
  • 繪圖工具： Piskel（網頁、免費）, LibreSprite（免費）, Aseprite（付費）

上傳前確認

  • 高 48，寬是 96（角色）或 48（物品）的倍數，8 格影格以內
  • 背景透明，沒有留下範本線
  • 每一格的四個角不能都被塗滿（都塗滿的話會被當成留著背景而擋下來）
  • 面向右邊，腳在最下面一列，每一格位置一樣

上傳

  1. 在系統匣選單「角色 > 製作…」裡選角色、道具或表情分頁。
  2. 點「+ 新增」，輸入名稱（最多 20 個字）。
  3. 每個動作選一張 PNG，或者拖到對應的格子裡。
  4. 儲存後會出現在你的清單裡。在同一個地方可以修改或刪除。
  • fps 已經填好建議值
  • 道具還要選種類（可投擲、食物、便便）和音效 wav
  • 也可以點更換角色、選道具、選表情視窗最前面的 + 卡片開啟
  • 你選的角色會馬上顯示
  • 朋友的畫面上，要等朋友開啟系統匣「角色 > 更換…」視窗，或點「取得新角色和道具」才會出現

使用食物和便便

  • 食物：右鍵點朋友，在「食物」裡選好，再點朋友
  • 再次選「可投擲」之前，每點一下就餵一次食物
  • 便便：fly 圖會畫成掉在地上的便便（不會被投擲，也不當食物用）
  • 你的角色吃飽了會拉出你選的便便
  • 朋友還沒收到的便便，在收到之前會顯示成預設便便

表情

  • 在「表情」分頁裡選 GIF、WebP、APNG、PNG 或 JPG
  • 應用程式會縮小到 64px，並照原速度儲存
  • 只有同一群組的朋友能看到
位置方式
頭頂我的角色選單「表情」（⌃⌥⌘E，Windows 是 Ctrl+Alt+E）
對話泡泡在訊息裡輸入 : 再選名稱，就會以 :名稱: 的形式放進去
狀態狀態和暱稱視窗「狀態」分頁裡的 Emoji 按鈕
回應在聊天記錄裡貼到訊息上
詳情
  • 最多選 16 個影格後儲存
  • 原檔最大 20MB，寬高最大 2048px
  • 名稱最多 20 個字，在群組裡不能重複
  • 不能用 : 和空格，因為會把訊息裡的 :名稱: 截斷
  • 預設表情的名稱（heart、question、exclamation、angry、lol、note、쪽지）也不能用

一次全部上傳

  • 把 PNG 打包成一個 zip，拖到製作視窗裡
  • 也可以在「一次加入」裡選 zip 檔或資料夾
  • 加入前會顯示每個檔案要放進哪一格
  • 名稱對不上的檔案，自己選格子
  • 上面「下載全部」的 zip 也是這些名稱，可以直接放進去試試

檔名就是動作名稱本身（不分大小寫，zip 裡有資料夾也沒關係）。

  • 角色： idle.png walk.png sleep.png poked.png throw.png hit.png jump.png eat.png wave.png happy.png offline.png
  • 道具：fly.png impact.png，音效 sound.wav（便便只要 fly.png）

用 Claude 或 Codex 技能製作

  • 在終端機裡安裝 Claude Code 或 Codex 外掛（貼上下面的指令）
  • 傳一張照片，說「幫我做一個 Huggybugi 角色」
  • 它會畫 11 個動作（需要的話也會畫便便、投擲物、食物），並給你可以用上面「一次全部上傳」的方法放進去的 zip
  • 新版本會隨外掛更新一起變
