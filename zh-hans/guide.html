角色和道具的制作方法

每个动作一张 PNG，各帧横向拼在一起。

用技能做 · 最简单

把技能 zip 上传到 Claude、ChatGPT 或 Gemini，再给一张照片，它会把画好的图给你看、跟你一起改，最后给你一个能直接导入的 zip。

下载技能并使用

复制规格去请 AI

把这个页面的规格复制成 Markdown，粘贴给 ChatGPT 或 Claude，它就会照着规格做。

上传

在托盘菜单里打开“角色 > 制作…”，选角色、道具或表情标签页，然后点“+ 新建”。写上名字（最多 20 个字），每个动作选一张 PNG，或者直接拖到那个格子里。fps 已经填好了推荐值。道具还能选种类（投掷物、食物、便便）和音效 wav。保存后就出现在你的列表里，在同一个地方可以修改或删除。换角色、选道具、选表情窗口最前面的 + 卡片点一下，也会打开对应种类的制作窗口。

朋友那边，要等他打开托盘的“角色 > 更换…”窗口，或者点托盘的“获取新角色和道具”时才会收到。你自己选的角色会马上显示。

食物道具要右键点朋友，在“食物”里选一个，然后点朋友就飞过去了。在重新选“投掷物”之前，每点一下都是喂食。

便便道具的 fly 图会被画成掉在地上的便便（不会被扔出去，也不会当食物）。你的角色吃饱时拉的就是你选的那个便便。朋友还没下载的便便，在下载之前都显示成默认便便。

表情

在“表情”标签页里选 GIF、WebP、APNG、PNG 或 JPG。应用会缩成 64px，最多取 16 帧，按原速保存（原文件最大 20MB，长宽各最多 2048px）。名字最多 20 个字，在群里不能重复。: 和空格不能用，会把消息里的 :名字: 断开；默认表情的名字（heart·question·exclamation·angry·lol·note）也不能用。

用在哪里：点自己的角色会弹出菜单，里面的“表情”（⌃⌥⌘E，Windows 是 Ctrl+Alt+E）会把选择窗口开在头顶上。在消息里打 : 就会列出名字，选一个就会以 :名字: 进到气泡里。状态和昵称窗口“状态”标签页的表情符号按钮可以把它放进状态。在聊天记录里还能当回应贴在消息上。只有同一个群的朋友能看到。

规格

  • 每帧 48×48，每个动作最多 8 帧（4 帧就是 192×48）
  • 透明背景，每个文件 200KB 以内（超了应用会重新保存压小。音效 wav 是 50KB）
  • 画成朝右（朝左的方向应用会自己翻转）
  • 角色和便便要贴着最下面一行、横向居中。投掷物和食物放在帧的正中间
  • 角色要把 48 格画得满一些（涂色的格子 800~1200 个，高 30~46 格，身体细的话画更大）。应用不会放大，画小了站在朋友角色旁边就显得小

角色动作

只要有 idle、walk、sleep 就行。其他动作缺了会用别的动作代替。没有 offline 的话，离线时会变成一块石头。

动作什么时候推荐缺了的话
idle 必需站着不动2 张，2fps
walk 必需走路时4 张，6fps
sleep 必需离开 30 分钟或锁屏（Zzz 由应用画）2 张，1fps
poked被戳2 张，8fpsidle
throw扔东西时3 张，10fpsidle
hit被打中时2 张，8fpspoked
jump躲开时、跳跃动作2 张，8fpsidle
eat被喂时、吃东西动作3 张，6fpshappy
wave跟上线的朋友打招呼、打招呼动作3 张，6fpshappy
happy被摸摸时、开心动作2 张，4fpsidle
offline离线（倒下的样子）1 张，1fps石头

道具动作

动作什么时候推荐缺了的话
fly 必需飞行途中。在制作窗口打开“飞行时旋转”，应用就帮你转（新建的默认是关的）。关掉旋转的投掷物会朝着飞行方向直飞，所以要画成朝右；关掉旋转的食物会照着你画的样子飞，所以要画成立正的。用多帧给它一点动静，看起来才不像定住了（比如弹跳、闪光）。便便是放在地上的样子投掷物 1 张，食物 1~4 张，12fps（便便 1 张）
impact打中的瞬间（只有投掷物，食物一到就吃掉）3 张，12fps应用画的星星迸裂

音效 wav 在碰到的瞬间（便便是落地时）响。没有的话，投掷物和食物就没声音，便便会用应用自带的“噗”声。

用 AI 做

图像 AI 做不到正好 48 像素。先画大，再缩小，然后修一修。

  1. 用下面的提示词生成
  2. 每一帧都缩到 48×48。插值方式一定要选邻近取样（Nearest Neighbor），不然会糊。
  3. 把背景抠成透明，再把各帧位置对齐

不用安装，在浏览器里：

  • Photopea（免费，和 Photoshop 差不多）：缩小用“图像 > 图像大小”，把重新采样设成 Nearest Neighbor。背景用魔棒工具（容差 0，关掉抗锯齿）点一下背景，按 Delete，然后导出成 PNG。
  • remove.bg（免费）：只想去背景的时候用。边缘可能会变模糊，所以要用在缩小前的大图上。

用技能做（最简单）

下载 huggybugi-character.zip，连同一张照片上传到 Claude、ChatGPT 或 Gemini，然后说“按 SKILL.md 用这张照片做一个 Huggybugi 角色”，它就会画出 11 个动作（你要的话还有便便、投掷物、食物），并给你一个能用下面的“一次全部导入”直接放进去的 zip。AI 要能运行代码（Claude 和 ChatGPT 要选能跑代码的模型）。每次都上传太麻烦的话，就把它注册成技能。之后只要给张照片说“做个 Huggybugi 角色”就行。

  • Claude（网页和应用）：设置里的 Capabilities（或 Customize > Skills）→ “Upload skill”，直接传 zip。需要开了代码运行的付费套餐
  • ChatGPT：套餐能用 Skills 的话，到 Skills → 上传，直接给它 zip。否则每次对话都把 zip 一起上传
  • Gemini（网页和应用）：在 Skills 里上传 zip（个人账号）
  • Gemini CLI：解压后把 huggybugi-character 文件夹放到 ~/.gemini/skills/

Claude Code 和 Codex 不用 zip，装成插件就行，有新版本时插件更新会一起带过来。应用制作窗口的“用 AI 做”里也能复制这些命令和规格。

能运行代码的 AI（ChatGPT、Claude 等）

格子能画得很准。把身体、眼睛、脚定义成椭圆这类简单形状，再用一个接收姿势数值（身体高度、眼睛形状、抬脚）画出单帧的函数来生成所有动作，这样各动作之间就不会走形。一起给它照片或图画，它会照着颜色和外形画。没有照片的话，先让它找几张这种动物或道具的可爱像素画看看再画，效果会好很多。

道具代码大概是这个样子（玩具锤的 fly 和 impact，还有默认便便）。上面示例里的玩具锤和便便图就是这段代码画出来的。文件名就用动作名 fly.png、impact.png 就行，下面的示例因为一次画两个道具，所以在名字前面加了前缀。

import math

COLORS = {'K': '#2b2233', 'Y': '#ffd23f', 'R': '#ff5a6e', 'F': '#9a6a48', 'N': '#7a4a24',
          'E': '#1b1420', 'P': '#ff9fb0'}
N = 48    # 48x48 的帧

def oval(x, y, cx, cy, rx, ry):  # 像素中心（+0.5）在椭圆内则为真
    return ((x + 0.5 - cx) / rx) ** 2 + ((y + 0.5 - cy) / ry) ** 2 <= 1

# 每个像素接收一个颜色字母拼成一帧，再把外轮廓换成 1px 的黑线（K）。
def render(fill):
    g = [[fill(x, y) for x in range(N)] for y in range(N)]
    solid = lambda x, y: 0 <= x < N and 0 <= y < N and g[y][x] != '.'
    return [''.join('K' if c != '.' and not (solid(x - 1, y) and solid(x + 1, y)
                                             and solid(x, y - 1) and solid(x, y + 1)) else c
                    for x, c in enumerate(row)) for y, row in enumerate(g)]

# 玩具锤：一张 fly（打开“飞行时旋转”后应用会转它）
def hammer(x, y):
    if 12 <= x <= 35 and 10 <= y <= 21:
        return 'Y' if x <= 14 or x >= 33 else 'R'
    if 21 <= x <= 26 and 22 <= y <= 41:
        return 'Y'
    return '.'

# impact：星星变大后碎成片散开（3 张）
def star(r):
    def fill(x, y):
        dx, dy = x + 0.5 - 24, y + 0.5 - 24
        a = math.atan2(dy, dx) + math.pi / 2
        edge = r * (0.55 + 0.45 * abs(math.cos(a * 5 / 2)))
        return 'Y' if math.hypot(dx, dy) <= edge else '.'
    return fill

def burst(color, k, n=6):
    def fill(x, y):
        r, s = 10 + k * 5, 4.4 - k * 0.45
        for i in range(n):
            a = i / n * math.pi * 2 + k * 0.2
            if oval(x, y, 24 + math.cos(a) * r, 24 + math.sin(a) * r, s, s):
                return color
        return '.'
    return fill

# 便便：一张 fly。贴着最下面一行的三层盘卷，最下层画眼睛、脸颊和嘴
TIERS = [(23.5, 38.8, 3.4, 1.9), (23.5, 41.9, 5.8, 2.2), (23.5, 44.9, 8.1, 3.1)]
DOTS = {(22, 36): 'F', (23, 36): 'F', (24, 36): 'F', (20, 44): 'E', (26, 44): 'E',
        (18, 45): 'P', (19, 45): 'P', (27, 45): 'P', (28, 45): 'P',
        (22, 46): 'N', (23, 46): 'N', (24, 46): 'N'}

def poop(x, y):
    if (x, y) in DOTS:
        return DOTS[(x, y)]
    for i, (cx, cy, rx, ry) in enumerate(TIERS):
        if oval(x, y, cx, cy, rx, ry):
            # 每层的下沿是搭在下一层上的凹槽
            return 'N' if i < len(TIERS) - 1 and y >= cy + ry - 1.1 else 'F'
    return '.'

ANIMS = {
    'hammer-fly': [render(hammer)],
    'hammer-impact': [render(star(9)), render(star(15)), render(burst('Y', 2))],
    'poop-fly': [render(poop)],
}

# 每个动作一张横向条带 PNG（1 倍，帧 48x48）
def save(name, frames):
    from PIL import Image, ImageColor
    img = Image.new('RGBA', (N * len(frames), N))
    for i, g in enumerate(frames):
        for y, row in enumerate(g):
            for x, c in enumerate(row):
                if c != '.':
                    img.putpixel((i * N + x, y), ImageColor.getrgb(COLORS[c]))
    img.save(name + '.png')

if __name__ == '__main__':
    for name, frames in ANIMS.items():
        save(name, frames)

AI 写的代码大概是这个样子（多基，11 个动作全都有）。上面示例里的多基图就是这段代码画出来的。装了 Pillow 的话可以直接跑，每个动作会存一张 PNG。

import math

COLORS = {'K': '#3a3640', 'G': '#9a98a3', 'g': '#7f7d88', 'W': '#fbf9f4', 'Y': '#f7c535',
          'y': '#e2a51f', 'E': '#2a1c18', 'P': '#ffb3c0', 'R': '#e8586a'}
N = 48    # 48x48 的帧
S = 1.5   # 把按 32 格定的尺寸换算到 48 格

def rnd(v):  # 0.5 向上取整（python 的 round 会取偶数，所以不用它）
    return math.floor(v + .5)

def u(v):  # 姿势偏移量换成 48 格上的整数像素
    return int(math.copysign(rnd(abs(v) * S), v)) if v else 0

def oval(x, y, cx, cy, rx, ry):
    return ((x + .5 - cx) / rx) ** 2 + ((y + .5 - cy) / ry) ** 2 <= 1

def tri(x, y, a, b, c):
    px, py = x + .5, y + .5
    s = lambda p, q: (px - q[0]) * (p[1] - q[1]) - (p[0] - q[0]) * (py - q[1])
    d = (s(a, b), s(b, c), s(c, a))
    return not (min(d) < 0 and max(d) > 0)

# 一只眼睛（以 3x3 为准）。dx、dy 是从眼睛左上角算起的偏移格数
def eye(dx, dy, kind):
    if kind == 'open':
        return ('W' if dx == dy == 0 else 'E') if 0 <= dx <= 2 and 0 <= dy <= 2 else None
    if kind == 'wide':  # 惊讶：4x4 加高光
        return ('W' if dx == dy == -1 else 'E') if -1 <= dx <= 2 and -1 <= dy <= 2 else None
    hit = {'closed': (dy == 1 and dx in (-1, 3)) or (dy == 2 and 0 <= dx <= 2),
           'happy': (dy == 0 and 0 <= dx <= 2) or (dy == 1 and dx in (-1, 3)),
           'hurt': -1 <= dx <= 3 and -1 <= dy <= 3 and (dx == dy or dx == 2 - dy)}[kind]
    return 'E' if hit else None

# 只接收姿势数值画出一帧。所有动作都用同一套形状。
# squash：+ 扁，- 长。feet：抬脚。flip：抬翅膀。lean：身体左右移动
def draw(bob=0, squash=0, feet=(0, 0), flip=(0, 0), eyes='open', mouth='', blush=False, lean=0):
    ry = (9 - squash) * S
    rx = min((13 + squash * .8) * S, 22.4)  # 别让压扁的身体超出格子
    by = (30.4 + min(bob, 1)) * S - ry + max(bob - 1, 0) * S
    cx = min(max((16 + lean) * S, rx + 1.4), 46.6 - rx)
    wl, wr = max(cx - rx + .3 * S, 4.5), min(cx + rx - .3 * S, 43.5)
    fy = by + 1.5 * S
    ey = rnd(by - 3 * S)
    shift = 3 + u(lean)  # 脸往右偏 3 格
    gy = rnd((30 + min(bob, 0)) * S) - u(max(feet))

    def foot(fcx, x, y, up):
        b = 47 - u(up)
        return b - 2 + min(0, u(bob + up)) <= y <= b and abs(x + .5 - fcx) <= (3.5 if y == b else 4.8)

    def pixel(x, y):
        body = oval(x, y, cx, by, rx, ry) or tri(
            x, y, (cx - 3.5 * S, by - ry + 2 * S), (cx + 3.5 * S, by - ry + 2 * S), (cx, by - ry - .8 * S))
        fin = oval(x, y, wl, fy - flip[0] * S, 2.6 * S, 1.8 * S) or oval(x, y, wr, fy - flip[1] * S, 2.6 * S, 1.8 * S)
        paw = foot(18.5, x, y, feet[0]) or foot(31.5, x, y, feet[1])
        # 像玩偶那样让脚看着在身体前面，所以先画脚再画身体
        if paw and y >= gy:
            return 'Y'
        if not body:
            return 'g' if fin else 'Y' if paw else '.'
        fx = x - shift
        e = eye(fx - 14, y - ey, eyes) or eye(fx - 31, y - ey, eyes)
        if e:
            return e
        if y in (ey + 2, ey + 3) and 21 <= fx <= 26:  # 喙
            return 'Y'
        if mouth == 'open':  # 吃东西时张开，能看到嘴里
            if ey + 4 <= y <= ey + 5 and 22 <= fx <= 25:
                return 'R'
            if y == ey + 6 and 22 <= fx <= 25:
                return 'Y'
        elif y == ey + 4 and (21 if mouth == 'chew' else 22) <= fx <= (26 if mouth == 'chew' else 25):
            return 'y'
        if blush and y in (ey + 3, ey + 4) and (11 <= fx <= 13 or 34 <= fx <= 36):
            return 'P'
        face = (oval(fx, y, 11 * S + .5, by - 2 * S, 3.8 * S, 3.6 * S)
                or oval(fx, y, 21 * S + .5, by - 2 * S, 3.8 * S, 3.6 * S)
                or oval(fx, y, 16 * S + .5, by + 3 * S, 8.2 * S, 5.2 * S))
        return 'W' if face else 'G'

    g = [[pixel(x, y) for x in range(N)] for y in range(N)]
    solid = lambda x, y: 0 <= x < N and 0 <= y < N and g[y][x] != '.'
    edge = lambda x, y: not all(solid(x + a, y + b) for a, b in ((1, 0), (-1, 0), (0, 1), (0, -1)))
    return [''.join('K' if c != '.' and edge(x, y) else c for x, c in enumerate(row)) for y, row in enumerate(g)]

ANIMS = {
    'idle': [draw(), draw(bob=1)],
    'walk': [draw(feet=(1, 0), lean=-1), draw(bob=-1), draw(feet=(0, 1), lean=1), draw(bob=-1)],
    'sleep': [draw(eyes='closed', bob=1, squash=1), draw(eyes='closed', bob=2, squash=1)],
    'poked': [draw(eyes='wide', squash=3), draw(eyes='wide')],
    'throw': [draw(flip=(0, 4), lean=-1), draw(flip=(0, 5), lean=-1, bob=-1), draw(flip=(0, -1), lean=1)],
    'hit': [draw(eyes='hurt', lean=-2, squash=1), draw(eyes='hurt', bob=1)],
    'jump': [draw(squash=3, flip=(-1, -1)), draw(bob=-3, squash=-1, feet=(2, 2), flip=(3, 3))],
    'eat': [draw(mouth='open'), draw(mouth='chew', bob=1, squash=1), draw(eyes='happy', blush=True)],
    'wave': [draw(flip=(0, 3), eyes='happy'), draw(flip=(0, 6), eyes='happy'), draw(flip=(0, 3), eyes='happy')],
    'happy': [draw(eyes='happy', blush=True, bob=-1), draw(eyes='happy', blush=True)],
    'offline': [draw(eyes='hurt', squash=3, bob=1, flip=(-1, -1))],
}

# 每个动作一张横向条带 PNG（1 倍，帧 48x48）
def save(name, frames):
    from PIL import Image, ImageColor
    img = Image.new('RGBA', (N * len(frames), N))
    for i, g in enumerate(frames):
        for y, row in enumerate(g):
            for x, c in enumerate(row):
                if c != '.':
                    img.putpixel((i * N + x, y), ImageColor.getrgb(COLORS[c]))
    img.save(name + '.png')

if __name__ == '__main__':
    for name, frames in ANIMS.items():
        save(name, frames)

一次全部导入

把 PNG 打成一个 zip，拖到制作窗口上，或者在“一次全部导入”里选那个 zip，每个格子就一次性填好了。没打包的文件夹就在“一次全部导入”里选文件夹。导入前会先告诉你每个文件进哪个格子，名字对不上的文件可以自己选格子。上面“全部下载”的 zip 也是这套名字，可以直接拿来试。

文件名就是动作名本身。大小写无所谓，zip 里有文件夹也没关系。

  • 角色： idle.png walk.png sleep.png poked.png throw.png hit.png jump.png eat.png wave.png happy.png offline.png
  • 道具：fly.png impact.png，音效 sound.wav（便便只要 fly.png）

上传前检查

  • 高 48，宽是 48 的倍数，不超过 8 帧
  • 背景透明，没留下模板线
  • 每一帧的四个角不能全被涂满（全涂满会被当成残留背景而拒绝）
  • 朝右，脚在最下面一行，每帧位置一致
