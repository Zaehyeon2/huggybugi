用图像 AI 做

  1. 在用一张图做里复制提示词。
  2. 粘贴到 ChatGPT、Gemini 之类的图像 AI。有角色照片的话一起发过去。
  3. 确认基本造型，然后选动作，或者说“你看着办”。
  4. 把拿到的图传到那个页面，就会按动作切好。
  5. 和多基对比大小，调整好后下载 zip。
  6. 把 zip 拖到应用的制作窗口。

只要有静止、走路、睡觉就能上传。

自己画

每个动作一张 PNG，各帧横向拼在一起。

规格

  • 角色每帧 96×48，物品 48×48。每个动作最多 8 帧（角色 4 帧就是 384×48）
  • 角色画在 96 格的中间。横向很长的角色可以用满整个宽度
  • 透明背景，每个文件不超过 200KB（超过的话应用会重新保存来压小）
  • 音效 wav 不超过 50KB
  • 正面，只有脸稍微朝右，或者整个朝右（朝左的由应用翻转）
  • 角色和便便要贴着最下面一行，水平居中
  • 投掷物和食物放在帧的中央
  • 角色大小：涂色的格子 800~1200 个，高 30~46 格（身体细的话再大一点）
  • 应用不会放大，画小了在朋友的角色旁边会显得小

角色动作

只要有 idle、walk、sleep 就行。其余的由“缺了的话”那一列的动作代替。

动作什么时候推荐缺了的话
idle 必需站着不动2 张，2fps
walk 必需走路时4 张，6fps
sleep 必需离开 30 分钟或锁屏（Zzz 由应用画）2 张，1fps
poked被戳2 张，8fpsidle
throw扔东西时3 张，10fpsidle
hit被打中时2 张，8fpspoked
jump躲开时、跳跃动作2 张，8fpsidle
eat被喂时、吃东西动作3 张，6fpshappy
wave跟上线的朋友打招呼、打招呼动作3 张，6fpshappy
happy被摸摸时、开心动作2 张，4fpsidle
offline离线（倒下的样子）1 张，1fps石头

道具动作

动作什么时候推荐缺了的话
fly 必需飞行期间。便便是掉在地上的样子投掷物 1 张，食物 1~4 张，12fps（便便 1 张）
impact打中的瞬间（只有投掷物，食物一到就吃掉）3 张，12fps应用画的星星迸裂
  • 打开“飞行时旋转”，应用就会让它转（新建的默认是关的）
  • 关掉的投掷物会朝着飞行方向飞，请画成朝右
  • 关掉的食物会按你画的样子飞，请画成笔直站立
  • 看起来不动的话，用帧加点动作（弹跳、闪烁）
  • 音效在碰到的瞬间响（便便是落地时）
  • 没有音效的话，投掷物和食物是静音的，便便会发出“噗”的一声

模板

  • 在制作窗口点“下载模板”，可以拿到每个动作都带示例的模板（应用里的仓鼠，道具是橡果）
  • 空白模板：2 帧、4 帧、8 帧、全部下载（zip）
  • 垫在下面的图层上画，画完关掉模板图层再保存
  • 红线是脚的基准线
  • 画图工具： Piskel（网页版，免费）, LibreSprite（免费）, Aseprite（付费）

上传前检查

  • 高 48，宽是 96（角色）或 48（物品）的倍数，不超过 8 帧
  • 背景透明，没留下模板线
  • 每一帧的四个角不能全被涂满（全涂满会被当成残留背景而拒绝）
  • 朝右，脚在最下面一行，每帧位置一致

上传

  1. 在托盘菜单“角色 > 制作…”里选角色、道具或表情标签。
  2. 点“+ 新建”，输入名称（最多 20 个字）。
  3. 每个动作选一张 PNG，或者拖到对应的格子里。
  4. 保存后会出现在你的列表里。在同一个地方可以修改或删除。
  • fps 已经填好推荐值
  • 道具还要选种类（投掷物、食物、便便）和音效 wav
  • 也可以点更换角色、选道具、选表情窗口最前面的 + 卡片打开
  • 你选的角色会马上显示
  • 朋友的屏幕上，要等朋友打开托盘“角色 > 更换…”窗口，或点“获取新角色和道具”才会出现

使用食物和便便

  • 食物：右键点朋友，在“食物”里选好，再点朋友
  • 再次选“投掷物”之前，每点一下就喂一次食物
  • 便便：fly 图会画成掉在地上的便便（不会被投掷，也不当食物用）
  • 你的角色吃饱了会拉出你选的便便
  • 朋友还没收到的便便，在收到之前会显示成默认便便

表情

  • 在“表情”标签里选 GIF、WebP、APNG、PNG 或 JPG
  • 应用会缩小到 64px，并按原速度保存
  • 只有同一群组的朋友能看到
位置方式
头顶我的角色菜单“表情”（⌃⌥⌘E，Windows 是 Ctrl+Alt+E）
气泡在消息里输入 : 再选名称，就会以 :名称: 的形式放进去
状态状态和昵称窗口“状态”标签里的 emoji 按钮
回应在聊天记录里贴到消息上
详情
  • 最多选 16 帧后保存
  • 原文件最大 20MB，宽高最大 2048px
  • 名称最多 20 个字，在群组里不能重复
  • 不能用 : 和空格，因为会把消息里的 :名称: 截断
  • 默认表情的名称（heart、question、exclamation、angry、lol、note、쪽지）也不能用

一次全部导入

  • 把 PNG 打成一个 zip，拖到制作窗口里
  • 也可以在“批量添加”里选 zip 文件或文件夹
  • 添加前会显示每个文件要放进哪一格
  • 名字对不上的文件，自己选格子
  • 上面“全部下载”的 zip 也是这些名字，可以直接放进去试试

文件名就是动作名本身（不分大小写，zip 里有文件夹也没关系）。

  • 角色： idle.png walk.png sleep.png poked.png throw.png hit.png jump.png eat.png wave.png happy.png offline.png
  • 道具：fly.png impact.png，音效 sound.wav（便便只要 fly.png）

用 Claude 或 Codex 技能做

  • 在终端里安装 Claude Code 或 Codex 插件（粘贴下面的命令）
  • 发一张照片，说“帮我做一个 Huggybugi 角色”
  • 它会画 11 个动作（需要的话也会画便便、投掷物、食物），并给你可以用上面“一次全部导入”的方法放进去的 zip
  • 新版本会随插件更新一起变
# Claude Code
claude plugin marketplace add Zaehyeon2/huggybugi
claude plugin install huggybugi@huggybugi

# Codex
codex plugin marketplace add Zaehyeon2/huggybugi
codex plugin add huggybugi@huggybugi
